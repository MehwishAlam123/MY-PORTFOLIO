### 3. 📂 Featured Engineering Projects — Revolving 3D Circle & Square Morph

  - **Revolving State:** While in motion or running via "Revolve Circle", projects orbit along a circular radar ring with glowing circular trajectory indicators and live telemetry (`REVOLVING IN CIRCLE`).

### 4. 🧊 Core Technologies & Systems — Separate 3D Technical Cubicals & Dynamic Cursor Swarm
- **16 Separate True 3D Technical Cubicals:**
  - Every technology is engineered as an independent, floating true 3D cubical box ($84\text{px} \times 84\text{px}$) with 6 distinct geometric faces (`face-front`, `face-back`, `face-right`, `face-left`, `face-top`, `face-bottom`).
  - Features microchip top caps, glowing telemetry side bars, back category tags, front icon/title panels, technical indices (`[01]`–`[16]`), status LEDs, and precision corner targeting brackets (`+`).
- **Dynamic Cursor Following & Swarm Motion:**
  - When moving the cursor across the arena, all 16 separate cubicals dynamically glide and follow wherever the cursor moves in a smooth, spring-damped trajectory.
- **Strict Separation (Fluid Pairwise Repulsion Physics):**
  - Just like the fluid separation behavior from the bubble system, all 16 cubicals maintain distinct, visible gaps ($105\text{px}$ minimum pairwise distance) and never bunch into an overlapping clump.
- **3D Continuous Tumble & Showcase Rotation:**
  - Cubicals dynamically tumble in 3D perspective with gentle upright elevation tilt and horizontal spinning showcase rotation.
  - Hovering or clicking snaps the cube directly to face the camera, highlights with intense cyan neon glow, and updates the **Tech Inspector HUD** with full specifications and project mappings.
- **Interactive Filtering & HUD Telemetry:**
  - Category filter chips (*All Cubicals (16)*, *AI & ML*, *Languages*, *Web & UI*, *Systems*) smoothly filter active cubicals.
  - Real-time **Tech Inspector HUD** providing production specs, architectural use cases, and project links.

## 🛠️ How to Run Locally

### Option 1: Direct File Opening
Double-click `index.html` in your file explorer to open it directly in Chrome, Edge, Firefox, or Safari.

### Option 2: Python HTTP Server (Recommended)
```bash
# In the project directory:
python -m http.server 8080
```
Then visit `http://localhost:8080` in your web browser.

### Option 3: VS Code Live Server
Right-click `index.html` inside VS Code and choose **"Open with Live Server"**.

## 🌐 Free 1-Click Deployment (GitHub Pages)

1. Initialize git and push to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Mehwish Alam portfolio"
   git remote add origin https://github.com/MehwishAlam123/portfolio.git
   git branch -M main
   git push -u origin main
   ```
2. In your GitHub repository, navigate to **Settings > Pages**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your website will be live in 1-2 minutes at:  
   `https://mehwishalam123.github.io/portfolio/`
